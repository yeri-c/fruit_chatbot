# 🍓 Fruit Expert Chatbot

An AI chatbot specialized in fruits, powered by Azure OpenAI.
Answers questions about fruit taste, nutrition, and more in a cute tone.

## Features

- 🍎 Expert answers about fruits
- 💬 Remembers recent conversation history
- 🌐 Streamlit web UI

## Tech Stack

- Azure OpenAI GPT-4o-mini
- Streamlit
- Python

## Setup

Create a `.env` file:

AZURE_OAI_ENDPOINT=your-endpoint

AZURE_OAI_KEY=your-api-key

AZURE_OAI_DEPLOYMENT=your-deployment-name

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
